## How to Use

### 1. Open the Project

Open the `index.html` file in your web browser to start using the Doggie Diaries Blog.

### 2. Write and Submit Posts

- Navigate to the **Post** section.
- Enter the **title** and **content** of your blog post.
- Submit your blog post, which will be stored locally in the browser using `localStorage`.

### 3. View Posts

You can read all posts on the **Home** page. Each post is displayed with its **title** and **content**.

### 4. Contact Us

Use the **Contact** page to send us a message. We will respond as soon as possible.
